# Lofiplayer 🎵

**Minimalistic 24/7 lo-fi music player for work, study, or relaxation.** Built with React, TypeScript, and Vite, Lofiplayer delivers a fast and seamless experience for streaming chill beats anytime, anywhere.

## 🚀 Features

- 🎧 **24/7 Lo-Fi Radio**: Continuous lo-fi music streaming.
- 🌙 **Minimalist Design**: Clean and distraction-free interface.
- ⚡ **Blazing Fast**: Powered by Vite for optimal performance.
- 🎨 **Smooth Animations**: Framer Motion for delightful transitions.
- 🗺️ **Type-Safe Routing**: TanStack Router for modern navigation.
- 📱 **Responsive**: Optimized for all devices.
- 🛠️ **Lightweight State Management**: Zustand for efficient state handling.

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite 6, TypeScript
- **Routing**: TanStack Router
- **State Management**: Zustand
- **Animations**: Framer Motion
- **Media Player**: React Player
- **Styling**: Tailwind v4
